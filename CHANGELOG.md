# Giga Wing Recomp — changelog

## 0.1.0-beta.1

First build. The 68000 and Z80 programs of *Giga Wing* (Takumi / Capcom, USA 990222) are translated to
C++ ahead of time and run on cps2recomp's own CPS-2 machine. The launcher, the in-game menu, save
states, run-ahead, the display options and every control are remappable.

This release is the toolkit's, before any game-specific work: Giga Wing's own features (cheats, stage
select, practice and so on) are still to come. See [ROADMAP.md](ROADMAP.md).
